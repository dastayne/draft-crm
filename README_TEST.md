# драфт CRM · PWA + Supabase Sync

## Что внутри
- `index.html` — текущая CRM, адаптация под мобилки, PWA-мета-теги, Supabase-синхронизация.
- `manifest.webmanifest` — установка на экран iPhone как веб-приложение.
- `service-worker.js` — базовый офлайн-кэш оболочки.
- `icons/` — простые иконки для теста.
- `supabase_setup.sql` — SQL для бесплатной облачной синхронизации.

## Быстрый запуск синхронизации
1. Создай бесплатный проект на Supabase.
2. Открой SQL Editor и выполни `supabase_setup.sql`.
3. В Supabase зайди в Project Settings → API.
4. Скопируй Project URL и anon public key.
5. Залей папку `draft_crm_pwa_supabase_v27` на Netlify / Vercel / любой хостинг.
6. Открой сайт на компе, нажми `Синк`, вставь URL, anon key, Sync ID: `main`.
7. Открой тот же сайт на iPhone, нажми `Синк`, вставь те же данные.
8. Теперь изменения должны прилетать между устройствами.

## iPhone
Открой сайт в Safari → Поделиться → На экран «Домой».

## Важно про шрифты
Шрифты не включены в архив. Сейчас файл оставляет CSS-ссылки на `./fonts/...`, но если папки `fonts` нет, браузер использует fallback-системные шрифты.
